# מיטל · שירותי משרד

Static landing page (HTML/CSS/JS, no build step), built from the Claude Design export "Meital Office Services".

- `index.html`: the page
- `styles.css`: styles
- `main.js`: settings at the top (`WHATSAPP_NUMBER`, `BOOKING_URL`, `WEB3FORMS_KEY`), WhatsApp links, the lead form (sent by email through Web3Forms) and the scroll animations

Preview locally: `python -m http.server 8090`, then open http://localhost:8090
